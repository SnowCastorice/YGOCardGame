### 磨损系统（Wear System）
- **参考**：CS2 枪皮磨损机制 + PSA 评级卡逻辑
- **核心机制**：
  - 卡片在开出时赋予唯一的磨损值（float value，0~1），决定卡面外观
  - 卡片价格在磨损基础上浮动，磨损越低价值越高
  - 开包时仅展示大致范围（如：崭新出厂 / 略有磨损 / 久经沙场 / 破损不堪 / 战痕累累），不显示精确数值
  - **鉴定系统**：玩家支付鉴定费后，揭示准确的磨损数值，同时展示评级（Grade，如 PSA 10 / 9 / 8 ...）
  - **报价系统**：鉴定完成后，系统根据磨损值 + 评级给出报价（玩家可据此决定出售或收藏）
- **类比现实**：类似 PSA/BGS 卡片评级 — 开包 = 裸卡入手，鉴定 = 送评封装，报价 = 市场估价
- **待细化**：磨损范围划分、外观表现方式、磨损对价格的量化影响、与稀有度的联动关系、鉴定费定价、评级标准
